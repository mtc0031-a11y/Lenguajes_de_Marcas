# Lenguajes_de_Marcas

En el primer ejercicio que es el de ajedrez:

Generación Dinámica: El tablero no está escrito manualmente en HTML; se construye mediante bucles anidados en JavaScript.

Lógica de Cuadrícula: Uso de display: grid para un alineamiento perfecto de 8x8.

Patrón de Colores: Algoritmo matemático (fila + columna) % 2 para alternar automáticamente los colores de las casillas.

Piezas Unicode: Utiliza caracteres estándar de ajedrez para una visualización ligera sin necesidad de imágenes externas.

En el segundo ejercicio que es el de juego_animacion

Mecánica de Salto: Implementada mediante clases dinámicas de CSS y eventos de teclado (Space).

Detección de Colisiones: Sistema de verificación en tiempo real que calcula las coordenadas exactas de los elementos en pantalla mediante getComputedStyle.

Puntuación Dinámica: Marcador que incrementa automáticamente mientras el jugador permanece con vida.
